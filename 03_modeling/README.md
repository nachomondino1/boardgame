# 03 — Modeling

Vacío por ahora: este proyecto no entrena ni corre un modelo. Lo más parecido es la heurística de recomendación de `../js/shared.js::recommendationScore` (combina duración, complejidad, "Jug Best" y puntaje personal/BGG para ordenar qué jugar hoy), pero vive en el frontend porque es puro cálculo sobre datos ya cargados, sin entrenamiento.

Si en algún momento esto crece a algo más armado (ej. un recomendador entrenado con tus partidas jugadas), va acá.
